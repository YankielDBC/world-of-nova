# World of Nova — Inspiración: Ítems de WoW (muestra de 1000)

> Muestra representativa de ítems de World of Warcraft (Retail) extraída de WoWpedia, organizada por categoría para inspirar el catálogo de objetos de World of Nova.

## Fuentes

- WoWpedia — Category:World of Warcraft items: `https://wow.gamepedia.com/Category:World_of_Warcraft_items`
- Wowhead (referencia bloqueada para scraping directo): `https://www.wowhead.com/items`

---

## Nota metodológica

- WoW tiene decenas de miles de ítems. Esta lista es una **muestra de ~1000 ítems** balanceada entre:
  - Equipamiento (armadura, armas, joyería, abalorios)
  - Consumibles (pociones, comidas, bebidas, elíxires)
  - Materiales de profesión (piel, tela, minerales, hierbas, recetas)
  - Basura / objetos de venta a NPC
- Las columnas de rareza y efecto están marcadas como "—" porque WoWpedia no expone stats/efectos de ítems de juego de forma estructurada. Para rellenar esos datos se requiere la API de Blizzard o scraping de Wowhead.

## Lecciones de diseño para World of Nova

1. **Categorías claras**: cada ítem debe tener un tipo (equipo, consumible, material, basura, receta) para definir su uso y valor.
2. **Rarezas visuales**: gris (basura), blanco (común), verde (poco común), azul (raro), morado (épico), naranja (legendario).
3. **Ítems de vendor**: necesarios como sink de loot y fuente de ingresos básicos.
4. **Materiales de profesión**: crean demanda y comercio entre jugadores.
5. **Consumibles apilables**: pociones y comidas deben tener uso claro en combate o recolección.
6. **Equipo procedural**: plantillas base + rareza + modifiers permiten miles de variaciones sin diseñar cada pieza a mano.
